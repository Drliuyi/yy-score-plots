# Publication reference files

This repository includes the two open-access Yu/Chen publication supplements
required by the source-audit and figure workflow:

- `raw/pwaf072_supplementary_table_1.xlsx`
- `raw/pwaf072_supplementary_figure_1.pdf`

`SOURCE_MANIFEST.csv` records their official source, role and expected SHA256.
They are redistributed for reproducibility under the source article's CC BY
license; copyright remains with the original authors.

Official main-figure JPGs, the UKB Olink processing-date resource and the pinned
CMAverse source archive remain excluded. The runner requests the processing
date file on first setup. CMAverse is installed from its frozen public commit
when the local source archive is absent.

Participant-level UK Biobank data are never distributed with this repository.
